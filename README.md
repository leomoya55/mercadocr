# MercaTico

A live Costa Rican online marketplace connecting local buyers and sellers, with multi-role authentication, product listings, and a full checkout flow.

🔗 **Live site:** [mercaticocr.com](https://mercaticocr.com)

## Features
- Multi-role authentication (buyers, sellers) secured with JWT
- Seller dashboards for managing listings
- Product browsing and buyer checkout flow
- Freemium model: free listings + paid "Verified Seller" and featured listing tiers

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MySQL
- **Auth:** JWT

## Getting Started
```bash
# Clone the repo
git clone https://github.com/leomoya55/mercadocr.git
cd mercadocr

# Install dependencies (backend and frontend)
npm install

# Set up environment variables
cp .env.example .env
# Fill in your DB credentials and JWT secret

# Run the app
npm start
```

## About
Built and maintained end-to-end — from database design (8+ tables) to deployment and ongoing bug fixes. Founded as a way to give independent Costa Rican sellers an accessible platform to reach buyers.
